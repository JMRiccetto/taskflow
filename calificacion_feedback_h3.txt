PROBLEMA 7 — Step definitions de US-03/US-04/US-05 usan stubs
------------------------------------------------------------------------

QUE PASA:
Los projects.steps.js y tasks.steps.js hardcodean respuestas en vez de llamar
a la API real. Los escenarios pasan, pero no validan el sistema. Si la API
tuviera un bug, los tests BDD no lo detectarian.

COMO ARREGLARLO — ejemplo para projects.steps.js:

    // Reemplazar el stub en "When el usuario crea un proyecto con:"
    When('el usuario crea un proyecto con:', async function (dataTable) {
      const data = dataTable.rowsHash();
      this.response = await api.post('/api/projects', {
        name: data.name,
        description: data.description,
      }, {
        headers: { Authorization: `Bearer ${currentUser.token}` }
      });
    });

    // Y el Given que registra al usuario debe ser real:
    Given('existe un usuario autenticado con email {string}', async function (email) {
      const res = await api.post('/api/auth/register', {
        email,
        password: 'ValidPass123!',
        name: 'Owner'
      });
      currentUser = { email, token: res.data.token };
    });

El mismo patron aplica para tasks.steps.js: cada When debe hacer la llamada
HTTP real en lugar de devolver un objeto hardcodeado.
